# Coding Agents in the Enterprise: companion toolkit

Tested tools and templates for the book *Coding Agents in the Enterprise:
Rolling Out Claude Code, Cursor, Copilot and Codex with Guardrails, Security
and Measurable ROI* by Prosperity Paul (ADB Books, 2026).

Every output printed in the book is in `examples/` and is regenerated by
`make examples`. The examples use a synthetic organisation, **Example Bank**
(regulated, 400 engineers).

## What is in it

| Folder | What it does | Chapter |
|---|---|---|
| `cost/` | Seat + metered cost model, cost per PR, break-even | 2 |
| `scorecard/` | Weighted vendor scorecard with must-have gates | 3 |
| `policies/` | Managed settings and hooks: Claude Code, Codex, Copilot, Cursor | 5 |
| `pilot/` | Sample size and difference-in-differences on synthetic data | 8 |
| `metrics/` | GitHub PR collector and quarterly scorecard | 10 |
| `templates/` | Policies, checklists, plans and rules files (Appendix A) | 1-12 |
| `examples/` | The outputs printed in the book | all |
| `tests/` | pytest suite for every tool and the hooks | all |

## Quick start

Needs Python 3.13. The only runtime dependency is PyYAML.

```bash
make install      # pinned: PyYAML, pytest, ruff
make test         # run the tests
make lint         # run ruff
make examples     # regenerate examples/*.md
```

On systems that block system-wide pip installs, use a virtual environment
(`python3 -m venv .venv && . .venv/bin/activate`) before `make install`.

Run a tool on your own inputs:

```bash
python3 cost/cost_model.py my-org.yaml
python3 scorecard/score.py my-scores.yaml
python3 pilot/sample_size.py --sd 1.1 --effect 0.3 --team-size 7 --icc 0.08
python3 pilot/did.py my-pilot.csv --metric prs_per_engineer
GITHUB_TOKEN=... python3 metrics/collect.py --repo owner/name \
    --since 2026-07-01 --out metrics.json
python3 metrics/report.py metrics.json --quarter 2026-Q3
```

`make data` regenerates the seeded synthetic datasets
(`pilot/synthetic-pilot.csv`, `metrics/sample-prs.json`); the result is
identical on every run.

## Disclaimer

- **Synthetic data.** Example Bank, its teams, people, repositories and pull
  requests are invented. "Tool A" to "Tool D" in the scorecard are not real
  products, and their scores say nothing about any vendor.
- **Verify prices.** Prices in `cost/example-bank.yaml` are list prices as
  of Nov 2026 and usage figures are assumptions. Vendors changed pricing
  several times in 2026. Check current pricing and your own usage data.
- **Not a security certification.** The policy files are examples checked
  against vendor documentation on 7 Nov 2026. Client-side controls are not a
  security boundary. Test them in your environment and have your security
  team review them before use.
