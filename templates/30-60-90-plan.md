# 30/60/90-day plan

**Sponsor:** [name] · **Lead:** [name] · **Start:** [date]

## Days 1-30: prepare and baseline

| Goal | Done when |
|---|---|
| Choose tools | Scorecard run; vendor questionnaire returned; contract signed |
| Guardrails | Managed settings, hooks and network allowlist deployed and tested |
| Pick teams | Pilot and comparison teams agreed; charter signed |
| Baseline | 4-8 weeks of PR, cycle-time and review data collected |
| Ready repos | Readiness checklist passed; AGENTS.md in each pilot repo |
| Train | Pilot engineers trained (half a day, hands-on) |
| Budget | Spend caps set per user and team; alert at [x]% |

## Days 31-60: run the pilot

| Goal | Done when |
|---|---|
| Use | Pilot engineers using agents most working days |
| Support | Weekly office hours; champion in each pilot team |
| Watch | Weekly metrics: cost, PR size, review wait, rework, incidents |
| Listen | Fortnightly pulse survey (trust, time saved, frustration) |
| Fix | Rules files and policies updated from what goes wrong |

Stop or pause early if: a Sev 1 incident, spend above [x], or review wait
doubles for two weeks running.

## Days 61-90: decide and scale

| Goal | Done when |
|---|---|
| Analyse | DiD estimate with confidence interval; cost per merged PR |
| Decide | Go / extend / stop, signed by sponsor, CISO and finance |
| Plan scale | Waves of teams, champions, training, budget for next 2 quarters |
| Govern | Acceptable-use policy published; quarterly scorecard owner named |
| Protect skills | Junior learning plan in place before wider rollout |

## Decision rule (agree on day 1)

Go if all are true:

- effect on [primary metric] is positive and its 95% CI excludes zero;
- change failure and rework are not worse beyond [x] points;
- cost per merged PR is below [x];
- no unresolved Sev 1 or Sev 2 incidents.
