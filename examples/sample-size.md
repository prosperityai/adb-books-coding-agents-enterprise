# Pilot sample size

| Input | Value |
|---|--:|
| Metric SD (per engineer) | 1.2 |
| Smallest effect worth detecting | 0.4 |
| Effect as share of SD | 0.33 |
| Alpha (two-sided) | 0.05 |
| Power | 80% |
| Team size | 8 |
| ICC | 0.1 |

| Result | Per group | Both groups |
|---|--:|--:|
| Engineers, assigned one by one | 142 | 284 |
| Engineers, assigned by team | 248 | 496 |
| Teams, assigned by team | 31 | 62 |

Design effect: 1.70. Assigning whole teams costs 106 extra engineers per group.
Use several baseline weeks per engineer to cut the SD, and check the
groups are balanced on baseline output before the pilot starts.
